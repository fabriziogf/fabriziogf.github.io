# Ironman Workout Library

Key sessions from three years of training (2023–2026) curated for reuse.

**Strenuous scale**: Low (<70 TSS) · Moderate (70–130 TSS) · High (130–200 TSS) · Very High (200+ TSS)
**Phases**: Base → Build → Sharpening → Race taper
**Length ranges**: Swim 2.0–4.5 km · Bike 1.5–6 h · Run 10–30 km
**Description format**: Warm-up → Main set (with intervals) → Cool-down

Sorted by type (ascending intensity), then duration within each type.
