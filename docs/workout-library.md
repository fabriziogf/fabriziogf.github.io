# Ironman Workout Library

Key sessions from three years of training (2023–2026) curated for reuse.
Each entry includes periodization phase, proximity to a target race, and a strenuous rating.

**Strenuous scale**: Low (<70 TSS) · Moderate (70–130) · High (130–200) · Very High (200+)
**Phases**: Base → Build → Sharpening (race-specific) → Race taper
