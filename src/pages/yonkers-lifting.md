This sits on top of the Post-Ironman Back, Hip & Core program I'm following, and runs alongside the [Yonkers training plan](/yonkers-plan/). It doesn't replace that program. It sequences it against the running, and adds the few things a marathon needs that a back-rehab program correctly doesn't include.

**The PT program is the base. Everything I've added is marked as an addition.** If any of it conflicts with what my physio says, the physio wins.

---

## How the two plans line up

I restarted strength on August 2, so that's PT week 1. That puts the phases here:

| PT phase | Dates | Marathon week |
|---|---|---|
| Phase 1 — Calm | Aug 2–15 | Base / Week 1 |
| Phase 2 — Rebuild | Aug 16–29 | Weeks 2–3 (peak run volume) |
| Phase 3 — Reload | Aug 30–Sep 12 | Weeks 4–5 |
| — | Sep 14–20 | Race week |

**One change to that sequence.** Phase 3 brings back the trap-bar deadlift and heavier squatting, and as written it starts on August 30 — the same day as the 32 km long run, in the biggest running week of the block. That's the worst possible collision.

So I'm holding Phase 2 through the peak week and starting Phase 3 on **September 1**, after the long run is done. Phase 2 gets two and a half weeks instead of two. The PT program already allows this — it says to repeat a phase if the back hasn't been quiet, and that there's no cost to doing so.

## Where the sessions go

Two sessions a week, matching the running plan. The principle is to keep hard days hard: lift on days that are already hard, and leave the easy days genuinely easy.

**Option A — long run Sunday**

| Day | Running | Lifting |
|---|---|---|
| Mon | Swim | Daily Reset only |
| Tue | Quality run | **Session A** — after the run, or that evening |
| Wed | Bike + short run | Daily Reset only |
| Thu | Easy run | **Session B** |
| Fri | Off | Daily Reset only |
| Sat | Bike or short run | Daily Reset only |
| Sun | **Long run** | Daily Reset only |

**Option B — long run Saturday**

| Day | Running | Lifting |
|---|---|---|
| Mon | Swim | Daily Reset only |
| Tue | Quality run | **Session A** — after the run, or that evening |
| Wed | Bike + short run | **Session B** |
| Thu | Easy run | Daily Reset only |
| Fri | Easy short run | Daily Reset only |
| Sat | **Long run** | Daily Reset only |
| Sun | Bike | Daily Reset only |

This moves the lifting off Monday, where the original running plan had it. Monday lifting puts a session the day before Tuesday's quality run, and the PT program specifically says to cut a session back when it lands the day before key work. Pairing it with Tuesday instead avoids the problem entirely.

Session B sits at least two days clear of the long run in both options.

## The Daily Reset

Ten minutes, seven days a week, unchanged from the PT program. Rest days, travel days, the morning after the 32 km run — all of them.

This is the part that actually changes the back, and it's the part most likely to get skipped once running volume climbs. It doesn't move. If a week goes badly and something has to give, give up a strength session and keep the reset.

90/90 breathing · cat-cow · modified curl-up · side plank (short lever) · bird dog · half-kneeling hip flexor stretch · supine figure-4. McGill descending pyramid on the middle three: 6 / 4 / 2 with 10-second holds.

## What I added for the marathon, and why

The PT program is built to settle a back and rebuild hip and trunk stability. It does that well. But it was written for post-Ironman recovery, not for a marathon build, and there are three gaps that matter when run volume goes from 50 to 67 km a week.

### 1. Calf and soleus work — the biggest gap

There is no calf work anywhere in the PT program. For a back-rehab block that's the right call. For a marathon build it's the thing most likely to break.

The soleus takes something like six to eight times bodyweight per stride when running, and it's the muscle that fails late in a marathon. It's also the most common casualty when weekly volume jumps by a third, which is exactly what mine is about to do.

**Added to Session A:**

| Exercise | Dose | Notes |
|---|---|---|
| Seated calf raise (knee bent 90°) | 3 × 15–20 | Bent knee takes the gastroc out and loads the soleus directly. This is the important one |
| Standing calf raise | 3 × 12 | Straight knee, gastroc |

**Added to Session B:**

| Exercise | Dose | Notes |
|---|---|---|
| Single-leg heel drop off a step | 3 × 10 / side | Slow lowering, 3 seconds down. Achilles and soleus under eccentric load |

None of this loads the spine, so it doesn't conflict with anything in Phase 1 or 2.

### 2. Downhill tolerance

Yonkers is hilly, and descending is eccentric quad work. Quads that haven't done it are what blow up on a rolling course — and in my case, the descents are also what will find the back late in the race.

The PT program already has lateral step-downs. I'm keeping them and changing the tempo rather than adding a new movement:

| Exercise | Change | Notes |
|---|---|---|
| Lateral step-down | 3 seconds down, no pause, drive up | Same exercise, eccentric emphasis |
| Rear-foot elevated split squat | 3 seconds down on the last set only | Keep normal tempo on the earlier sets |

Slow eccentrics are demanding. Not in the same week as the peak long run — normal tempo the week of August 24–30.

### 3. Ankle stiffness

Cheap, and it helps running economy. Low dose because it's impact on top of already climbing run volume.

| Exercise | Dose | When |
|---|---|---|
| Pogo hops | 3 × 20 | Phase 2 only. Drop from September 7 |
| Single-leg balance, eyes closed | 45s / side | Any phase, end of session |

Pogos come out during the taper. There's no fitness left to gain from them at that point and it's needless impact.

## The sessions

### Phase 1 · through Aug 15 — Calm

Marathon week 1. Follow the PT program's Phase 1 session as written, plus the calf work. No axial loading, three or more reps in reserve.

Glute bridge (double then single-leg) · split squat · low-box step-up · suitcase hold · chest-supported row · band pull-apart · dead bug · half-kneeling Pallof press

**Added:** seated calf raise 3 × 15, standing calf raise 3 × 12, single-leg balance.

### Phase 2 · Aug 16 – Aug 31 — Rebuild

Marathon weeks 2 and 3, including the peak. Held an extra half-week so Phase 3 doesn't collide with the 32 km run.

**Session A — Squat + Push + Carry**

Goblet squat 3 × 8 · RFE split squat 3 × 8 · hip thrust 3 × 10 · suitcase carry 3 × 30–40 m · push-up or DB bench 3 × 10 · Pallof press 3 × 10 · dead bug 3 × 8 · side plank full lever 3 × 20–30s

**Added:** seated calf raise 3 × 15–20, standing calf raise 3 × 12, pogo hops 3 × 20

**Session B — Hinge + Pull + Carry**

Pull-through 3 × 12 · single-leg RDL 3 × 8 · reverse lunge 3 × 8 · lateral step-down 3 × 8 *(3s eccentric)* · chest-supported row 3 × 10 · face pull 2 × 15 · farmer's carry 3 × 40 m · bird dog 3 × 8

**Added:** single-leg heel drop 3 × 10 / side, single-leg balance

**Week of Aug 24–30 — peak running week.** Cut every accessory to 2 sets, keep the main lifts, normal tempo on the step-downs, and skip the pogos. The PT program's own auto-regulate rule. That week the running is the priority and the lifting is maintenance.

### Phase 3 · Sep 1 – Sep 12 — Reload

Marathon week 4 and the first taper week. The loaded hinge comes back, but with a ceiling.

**Session A — Squat + Push + Anti-Rotation**

Goblet squat 3 × 8 · RFE split squat 3 × 8 · hip thrust 3 × 10 · lateral step-down 3 × 8 · push-up or DB bench 3 × 10 · half-kneeling press 2 × 8 · Pallof press 3 × 10 · dead bug 3 × 8

**Added:** seated calf raise 3 × 15–20, standing calf raise 3 × 12

**Session B — Hinge + Pull + Anti-Lateral-Flexion**

Trap-bar deadlift 3 × 8 · single-leg RDL 3 × 8 · Copenhagen plank short lever 3 × 20s · reverse lunge or step-up 3 × 8 · single-arm row 3 × 10 · band pull-apart 2 × 15 · side plank with top-leg lift 3 × 30s · suitcase carry 3 × 40 m

**Added:** single-leg heel drop 3 × 10 / side

**Two changes to Phase 3 for the marathon:**

- **Trap-bar deadlift stays light.** The PT program says to start light enough to feel silly, and during a marathon taper it should stay there. Three or four reps in reserve, and the load doesn't climb week to week. The point is to reintroduce the pattern, not to build strength I can't express by September 20.
- **Front squat stays out.** The PT program allows goblet or front squat in Phase 3. Goblet only for these two weeks — no axial loading during peak running.

### Race week · Sep 14–20

| Day | Session |
|---|---|
| Mon 14 | Daily Reset + one light session: warm-up, glute bridge, split squat bodyweight, suitcase hold, Pallof press, dead bug. No loading that leaves soreness |
| Tue–Sat | Daily Reset only |
| Sun 20 | Race. Reset in the evening if it helps |

Nothing heavy after Monday. The last session that builds anything was September 12.

## Conflicts I'm watching

**Phase 3 lands in the taper.** Trap-bar deadlifts and Copenhagen planks are the two most demanding items in the whole program, and they arrive in the two weeks when I should be shedding fatigue. Capping the load is the compromise. If race-week freshness looks off, Session B on September 8–12 is the first thing to cut.

**The hip thrust cue matters more now.** Finish with the pelvis tucked, never arched. Running with any lumbar extension bias is what puts the back at risk over three hours, and a hip thrust finished badly trains exactly the wrong pattern.

**The left side.** The PT program notes the bursitis, the lateral knee, and the back all landing on the left is a pattern rather than a coincidence, and that the weaker side sets the load on every unilateral lift. That gets more important as run volume climbs, since running is unilateral and a 34% volume increase will find the asymmetry.

**The 24-hour rule.** Judge every session by how the back feels the next morning. A session on Tuesday that feels fine but leaves the back sore on Wednesday means it was too much — and Wednesday is a bike day, which will hide it until the long run.
